# LeadFlow CRM

Демонстрационная мини-CRM для небольшого бизнеса. Интерфейс на русском языке, адаптивная Kanban-доска, аналитика, журнал активности, CRUD сделок и экспорт CSV.

## Запуск

```bash
cd leadflow
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000 . Документация API: http://127.0.0.1:8000/docs .

База `leadflow.db` создаётся автоматически и заполняется **вымышленными** данными при первом старте. Для очистки демо-базы остановите сервер и удалите `leadflow.db`. Для другой БД задайте `LEADFLOW_DB=/path/to/file.db`.

## Возможности

- KPI: сумма активных сделок, число активных заявок, конверсия, выручка закрытых.
- Управление заявками: создание, поиск, редактирование, удаление, смена статуса (в том числе перетаскиванием).
- Аналитика по этапам и журнал последних изменений.
- Экспорт данных в Excel-совместимый CSV (UTF-8 BOM).
- API FastAPI и SQLite, встроенная валидация Pydantic, автоматические тесты.

## Тесты

```bash
pip install pytest httpx
pytest -q
```

**Важно:** это MVP для локальной демонстрации, не готовая публичная CRM. Нет учётных записей, авторизации, разграничения прав, резервного копирования и ограничений на запросы. Не размещайте приложение в открытом интернете или с реальными клиентскими данными без этих доработок.

Технологии: Python, FastAPI, SQLite, HTML, CSS, JavaScript.
